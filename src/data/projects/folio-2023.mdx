# Folio 2023

This website was created back in 2023 when I was applying to SUTD for my undergraduate studies.
Aside from my diploma, I wanted a differentiating factor to make my application stand out,
and at the time, Three.js and WebGL were topics I had just started learning about,
so it made sense to combine the two to create a website that showcased my skills and interests.

This site was built using Vite, vanilla JavaScript, Three.js for the 3D elements, and GSAP for animations.
The background particles are created with a shader written in GLSL.
