## H2 – Code

Inline `code` looks like this inside a sentence.

### Fenced code block (plain)

```python
print("Hello, World!")
```

### Fenced code block (language)

```ts
type User = {
    id: string
    name: string
    roles: string[]
}

function greet(user: User) {
    console.log(`Hello, ${user.name}!`)
}
```
