# Audio Visualiser

This is a 3D audio visualiser web app that I built with React, Three.js, and the Web Audio API.
It captures audio from the user's microphone and visualises it in real-time using a dynamic 3D mesh.

My main reason for building this was to learn more about working with the Web Audio API and Three.js shaders.

I might revisit this project again in the future to make it visualise music instead,
which will be more interesting than just microphone input.
