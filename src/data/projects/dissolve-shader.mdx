# Dissolve Shader in Three.js

This is a simple demo of a dissolve shader effect using Three.js and GLSL.

It uses three-custom-shader-material to inject shader code into Three.js's MeshStandardMaterial.
This allows me to leverage the existing lighting and PBR calculations of MeshStandardMaterial,
while adding custom effects like, in this case, noise-based dissolving.

The effect is driven by simplex noise and a time uniform, to create the animated dissolving appearance.
