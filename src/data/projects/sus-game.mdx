# SUS-GAME - Sustainability Educational Game

## Context

In early 2025, I took part in a sustainability trip to Kyoto, organised by SUTD's Sustainability Office.
That trip included a deliverable: design a product that could help raise awareness about sustainability issues.
My group decided on creating an educational game that could interactively teach players about recycling.

## The Game

The gameplay is extremely simple, given the target audience of young children.
The player can pick up bins of different colours, representing different types of waste (general waste, recyclables, and donations).
The player must then sort the waste scattered around into the correct bins, taking damage for incorrect sorting.
The bin can then be dropped off at the corresponding station to earn points.

## Development

- I built the game with the Phaser 3 framework in TypeScript, with Vite as the build tool.
- I created the game map using [Tiled](https://www.mapeditor.org/).
- I drew the art assets in CLIP STUDIO PAINT.
