# About Wayfare

A hotel booking website. This was our main project for the 50.003 Elements of Software Construction course at SUTD.
Developed with React, TypeScript and the Mantine UI library, and features a custom 3D hero section built using Three.js, React Three Fiber, and some custom GLSL shaders.

We collaborated as a team of 8 members, with 6 members focusing on frontend development (including myself), and 2 members focusing on backend development using NestJS and Supabase.

The UI/UX design was done using Figma, and we followed Git branching strategies to manage our codebase effectively.

Unfortunately, the backend can't stay up permanently because of free-tier limits, so there's a video demo if you'd like to see the full user flow.
