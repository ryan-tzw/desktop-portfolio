# Simple Neural Network from Scratch

This project implements a simple feedforward 2-layer neural network from scratch using Python and NumPy.
It includes forward propagation, backpropagation, and training using gradient descent.
The network is trained on the MNIST dataset of handwritten digits to perform digit classification,
and achieves ~88% accuracy in spite of its simplicity.

The workflow loads and preprocesses CSV data using Pandas, normalises the pixel values,
one-hot encodes the labels, and uses NumPy to build and train the neural network,
implementing ReLU activations, softmax outputs, forward/backward propagation, and gradient descent.

This project came about because I was curious about how neural networks work under the hood,
so I decided to create a basic version of a neural net from scratch without relying on
high-level libraries like TensorFlow or PyTorch, to deepen my understanding of the underlying mechanics.
