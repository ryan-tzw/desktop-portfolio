# Desktop-style Portfolio

My personal portfolio website designed to look and feel like a desktop operating system interface.

🔗 **Live Site:** https://www.ryantzw.dev/

## 🛠️ Tech Stack

- **React** + **TypeScript** - UI framework and type safety
- **Vite** - Build tool and dev server
- **Tailwind CSS** - Styling
- **Zustand** - State management
- **dnd-kit** - Drag and drop functionality
- **MDX** - Rich project content
